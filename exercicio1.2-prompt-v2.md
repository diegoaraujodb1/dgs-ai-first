### Pergunta 1 - Qual o prazo de devolução para carga perigosa?

> Conforme a Política de Devolução (POL-001, seção 3.2), cargas classificadas como perigosas (classes 1 a 6 da ANTT) estão **expressamente excluídas** da política de devolução padrão. A documentação não prevê prazo alternativo para esse tipo de carga.
>
> Para obter orientação específica sobre devolução de carga perigosa, recomendamos escalar para o supervisor responsável.
>
> [Fonte: POL-001 §3.2] — [Prazo para carga perigosa não encontrado na documentação — recomendamos escalar para o supervisor]

### Pergunta 3 - Quanto custa o frete para 600kg para Manaus?

> Conforme o procedimento PROC-042-v2, seção 2, para cargas acima de 500kg com destino à Região Norte, o cálculo é:
>
> **Frete = valor base × 1,8**
>
> O multiplicador regional aplicável é **1,8** (Região Norte). Contudo, o valor base do frete não consta na documentação disponível, portanto não é possível calcular o valor final.
>
> Para obter o custo exato, recomendamos escalar para o supervisor responsável.
>
> [Fonte: PROC-042-v2 §2] — [Valor base não encontrado na documentação — recomendamos escalar para o supervisor]
